# metalearning4gliomaradiogenomics
Here is sourece codes, alongside the data for statistical analysis, and supporting materials for manuscript "A 3D Transfer-Learning Framework for Noninvasive Prediction of Multiple Glioma Molecular Biomarkers from Multiparametric MRI"

![Pipeline of study is shown as follow:](https://github.com/FORRESTHUACHEN/metalearning4gliomaradiogenomics/blob/main/Figures/Figures1.png)
<div align="center">
Overview of the study design. (A) Data acquisition. A multicenter dataset of 2,933 glioma patients was compiled from six public repositories for model development and internal validation, comprising 1,140, 2,445, and 1,241 eligible samples for the 1p/19q, IDH, and MGMT prediction tasks, respectively. Furthermore, an independent external validation cohort of 494 patients was assembled from three public datasets, yielding 125, 213, and 130 eligible samples for the respective tasks. (B) Preprocessing. mpMRI images were reconstructed from 2D slices into 3D volumes and resampled to an isotropic voxel size of 1.0 *1.0 *1.0 mm³. Skull stripping was performed using the pre-trained HD-BET deep learning model. (C) Experiment paradigm. Glioma molecular biomarkers analysis model was trained based on data for IDH task, analysis models for another two tasks follow transfer learning methodology. External validations were executed independently for three tasks. (D) Glioma molecular biomarkers prediction model architecture.
